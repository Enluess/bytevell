# Professional Web Design Guidelines

When designing or coding a web interface, adhere to the following strict guidelines to produce a professional, non-generic, and brand-specific result.

## 🚫 Banned List (AI Slop Indicators)
- **NO purple-to-blue linear gradients** for backgrounds (this is the most cliché AI signature).
- **NO generic emoji icons** (🚀 ✨ 💡). Use real SVG icon sets.
- **NO meaningless glassmorphism** or stacked blur cards without purpose.
- **NO direct copying** of the "Hero title + subtitle + two buttons" template.
- **NO stock-like** 3D renders or illustrations.
- **NO uniform spacing and card sizing** across all sections. Ensure a clear visual hierarchy.

## 🎨 Brand Identity (Determine First)
- Select **1 Main Color**, **1 Neutral Color**, and **1 Accent Color** tailored to the subject. (Avoid purple-blue combinations).
- Choose **one heading font** (a characterful serif or display font) and **one body font** (a highly legible sans-serif font).
- Use an **8px-based spacing system**: 8, 16, 24, 32, 48, 64, 96px.

## 📐 Typography & Layout
- Create a true hierarchy in headings: `h1` should be distinctively large, while `h2` and `h3` scale down proportionately.
- Inter-section spacing must come from the 8px fixed scale. **No arbitrary pixel values**.
- Build an **asymmetrical or broken symmetry grid**. Avoid centering everything or using equally sized columns everywhere.

## 📝 Content Rules
- Write **real, meaningful text**. Do NOT use "Lorem ipsum" or fabricated statistics.
- Avoid generic headings like "Best Solution". Use **brand-specific claims**.
- Each section must focus on a **SINGLE core message**. Do not cram three different ideas into one block.

## 🔎 Micro-Details (Professional Polish)
- Always define **hover states** for buttons and interactive cards. Never leave them static.
- Derive shadows and borders from the brand colors, not just default grays.
- Ensure all icons belong to the **same style family** (e.g., all outline or all solid).

## ⚙️ Technical Rules
- Develop with a **Mobile-First** approach and test across all breakpoints.
- Ensure the contrast ratio meets **WCAG AA** accessibility standards.
- Avoid unnecessary libraries or animations. Prioritize **fast load times**.

## 🏁 Completion Condition
Do NOT simply state "the design looks professional."
You MUST present the site visually (or provide evidence) and explicitly list:
- Where the brand colors were used.
- Which font pairing was applied.
- Exactly how the 8px spacing system was implemented.
Do not consider the task complete without this evidence.
